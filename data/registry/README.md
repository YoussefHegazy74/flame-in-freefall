# Registry Files

**Snapshot date:** 2026-11-08
**Status:** Generated metadata plus human-reviewed annotations. No raw NASA data.

This directory is the committed, machine-readable foundation of the project. It records what NASA PSI publishes, which files are exposed, which summary tables were inspected, and how each investigation is classified for the MVP.

Every mechanical value here comes from the NASA PSI API or from a downloaded and checksummed file. Curated roles and limitations come from `annotations.json`. Do not hand-edit the generated files; regenerate them with the scripts in `scripts/`.

## Invariants

1. `file_count` counts only `added` entries. It never includes `experimentalTable` entries.
2. `experimental_table_count` counts the current `experimentalTable` list.
3. `experimental_table_only_count` counts experimental tables whose file name is absent from `added`.
4. `distinct_public_artifacts = file_count + experimental_table_only_count`. Do not add the full experimental-table count, because 8 tables are already in `added`.
5. `archive_status` is:
   - `available` when `file_count > 0`;
   - `experimental_table_only` when `file_count == 0` and `experimental_table_count > 0`;
   - `no_public_files` when both are zero.
6. `registered_total_bytes` is the source `totalFileSize`, not the sum of the exposed `added` file sizes.
7. `GB` means 10^9 bytes everywhere in this repository.
8. A table statistic in `annotations.json` must match the exact downloaded file. `sha256` is the checksum of the raw bytes.
9. `data_rows` counts non-empty data rows after the header. `physical_rows` counts every row after the header, including blank rows.
10. A record is never labeled `inaccessible`. Use `archive_status` plus the curated role.

## Regeneration

```bash
# From the live PSI API.
python3 scripts/fetch_psi_metadata.py

# From cached detail JSON, no network.
python3 scripts/fetch_psi_metadata.py --details-dir /tmp/psi_details

# Verify no drift against the committed snapshot.
python3 scripts/fetch_psi_metadata.py --check

# Rebuild the curated catalog.
python3 scripts/build_mvp_catalog.py
python3 scripts/build_mvp_catalog.py --check
```

`--check` never writes. It exits 1 and prints every changed accession, field, and value.

## What is not here

- Raw NASA files. They are large and stay outside Git.
- Parsed or canonical Parquet tables. Phase 1 builds them under `data/interim/` and `data/processed/`, which are gitignored; this directory holds only their committed schema and manifests.
- Credentials, tokens, or presigned URLs. None are stored in this repository.
- Team member names or roles. The public challenge profile does not expose a verified roster.

Phase 1 adds these committed registry files:

| File | Purpose |
|---|---|

| `experimental_table_schemas.json` | Exact header, row counts, encoding, and checksum for all 22 experimental tables. |
| `canonical_schema.json` | Implemented Arrow schema, primary keys, and descriptions for the 13 canonical tables. |

For the field-level meaning of every column, see `DATA_DICTIONARY.md` §3. For the source-level narrative, see `DATA_SOURCES.md`. For the pipeline contracts, see `docs/decisions/0002-phase-1-pipeline-contracts.md`.
